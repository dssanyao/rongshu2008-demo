# 榕树下旧时光 · 榕树下 2005–2008 全栈前端复刻 v3（静态预览）

按用户提供的 **8 张截图（2007-12-29 为主）+ Wayback Machine 真实抓拍**重建的榕树下前端复刻站。这是 **GitHub Pages 静态预览版**：全部页面由 Node 原版预渲染导出，可在线浏览；完整可交互版（含发帖、回复、登录、后台精选同步）在源码包中以 Node 运行。

- 在线预览：https://dssanyao.github.io/rongshu2008-demo/
- 完整工程（含 server.js / seed.js / README 已知偏差）：见交付包 `rongshu2008-v3.zip`

## 本版口径

- 时间锚点 **2007-12-29**；首页统计“现有文章 3,509,592 篇，最新发表 724 篇”；770px 定宽。
- 8 类页面：首页、社团综合首页、望海文学社（7,951 篇 / 266 页）、文章《时光深处的老街》（编号 3912856，阅读 8,952 次）、论坛综合首页、Q帖（总共 12,321,232 篇主题）、帖子《悲伤，逆流成河》（阅读 649 次）、网文人气周榜（第 1 名思远人，总分 345,028，总共 1,082 篇）。
- 种子：28 频道、80 社团、43 版块、449 篇文章、837 条帖子。
- 全部广告位与空白占位白框已删除并收拢；导航为单排 5 项（v3.1，2026-11-08）：首页、社团、社区、状元阁、鬼故事，15px 加粗。
- v3.2（2026-11-08）：网站改名为**榕树下旧时光**，页脚全站统一为 `©️2026 榕树下旧时光`（旧链接行、ICP、1997-2006 公司版权行已删）；被删导航项对应的 9 个页面已删除（有声文学馆、炫动读书、付费中心、大学生在线、中学生天地、书店、随心秀、帮助、搜索——访问 404；例外：精品阅读为真实版块，保留）；首页日期自动同步为当日；8 处图片占位由本地生成图片填充（public/img/，SVG，无外链）。
- 正文大多佚失，30 篇有演示正文、其余只有元数据。**不宣称像素级**，详见完整工程 README 第六节“已知偏差”。

## 静态预览的边界

- 浏览全部有效：首页、28 频道、80 社团、43 版块、449 篇文章、837 条帖子、排行榜、停站公告。（搜索页已于 v3.2 删除。）
- 不可用：登录/注册、发帖/回复/加精、入社申请、后台 `/admin` 的全部操作（静态页无后端）；版块分页链接只显示第 1 页内容。
- 本地完整运行：`node seed.js && node server.js`，打开 http://localhost:8080/
