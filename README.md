# 榕树下 2005–2008 · 全栈前端 1:1 还原复刻 v2（静态预览）

按 **2008-01-01 真实存档**重建的榕树下前端复刻站。这是 **GitHub Pages 静态预览版**：全部页面由 Node 原版预渲染导出，可在线浏览；完整可交互版（含发帖、回复、登录、后台精选同步）在源码仓库中以 Node 运行。

- 在线预览：https://dssanyao.github.io/rongshu2008-demo/
- 完整工程（含 server.js / seed.js / README 已知偏差）：见交付包 `rongshu2008-v2.zip`

## 静态预览的边界

- 浏览全部有效：入口门户、登录后主页、28 频道、80 社团、43 版块、419 篇文章、862 条帖子、排行榜、停站公告。
- 不可用：登录/注册、发帖/回复/加精、入社申请、后台 `/admin` 的全部操作（静态页无后端）；版块分页链接只显示第 1 页内容。
- 本地完整运行：`node seed.js && node server.js`，打开 http://localhost:8080/
